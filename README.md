# 🧮 Maths Quiz Game

An interactive mathematics quiz game built with **HTML, CSS, and JavaScript**.

The project provides a browser-based quiz experience with multiple mathematics categories, difficulty levels, timed questions, hints, score tracking, quiz history, and a demo admin mode.

## 🚀 Live Demo

[Play Maths Quiz Game](https://astounding-florentine-684811.netlify.app/)

## ✨ Features

- 🎯 Interactive mathematics quiz
- 📚 Multiple categories:
  - Sets
  - Relations & Functions
  - Limits
- 🎚️ Three difficulty levels:
  - Easy
  - Medium
  - Hard
- ⏱️ Timed questions
- 💡 Hint system
- ⏭️ Skip question functionality
- 🔀 Randomized questions and answer options
- 📊 Score and performance statistics
- 🏆 Achievement system
- 📜 Quiz history stored using browser `localStorage`
- 🔊 Sound and text-to-speech feedback
- 👨‍💻 Demo admin mode
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Browser Local Storage
